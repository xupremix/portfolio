\section{Selected Projects}

\cvproject
  {incin: Compile-Time Safety for Machine Learning Code}
  {Rust, Machine Learning}
  {A machine-learning framework I created as my BSc thesis project.}
  {
    \begin{itemize}
      \item Explore compile-time checks for tensor shapes and invariants to make model code structurally safer and easier to reason about.
      \item The longer-term goal is to help AI research agents produce valid machine-learning code through clear architectural rules and compiler feedback.
    \end{itemize}
  }
